# Plano de Ação — Residencial Moove Tijuca

Painel de acompanhamento das ações dos proprietários (Unidade 804 e Comissão de Representantes):
jurídico, auditoria técnica, financeiro, documentação/cartório, governança e comunicação.

## Uso
Abra o `index.html` no navegador, ou publique via **GitHub Pages** (Settings → Pages → branch `main` → `/root`).

- Dashboard analítico ao vivo (progresso, status, categoria, prioridade, prazos vencidos).
- Tabela editável: status, prioridade, responsável, início, prazo e observações.
- Filtros por categoria/status e busca; incluir/editar/excluir ações.

## Observação importante
Esta é a **versão autônoma**: os dados são salvos no `localStorage` do navegador de cada
pessoa (não são compartilhados automaticamente entre dispositivos). Vem pré-carregada com as
ações propostas a partir do histórico do caso.

A versão **colaborativa ao vivo** (edição compartilhada em tempo real entre os proprietários)
roda no claude.ai e não depende deste repositório.

> Ferramenta de uso interno dos proprietários. Não constitui aconselhamento jurídico definitivo.
